# My Dream Coding Project: EcoTrack
## Project Overview
**EcoTrack** is an app designed tp help users track their daily carbon footprint and make small, sustainable choices that add up to a big impact.

It's built using **HTML, CSS** and **JavaScript** - but one day, i want to expand it into full web platform!

## Project Goals 
- Build a user-friendly dashboard that tracks:

    - Energy use
    - Transportation impact
    - Food consumption patterns
- Display personalized reports using:
    - `console.log()` to debug progress
    ``` 
    if (carbonScore < 50) {
      console.log("Great job staying eco-friendly!");
    } else {
      console.log("Let's find ways to reduce your footprint!");
    }
    ```
